- **An operator can hold a box stopped** (#3721). `containarium stop --hold <box>` (`StopContainer` with `hold: true`) stops a box and keeps it stopped: the daemon turns `boot.autostart` off for it, refuses wake-on-HTTP for its routes with `503` and logs the refusal, and fails `ProvisionSkillBox`, `RunAgentSkill` and `RunCrew` with `FailedPrecondition` instead of starting it. The hold is stored on the instance, so it survives a daemon, Incus or host restart, and `GetContainer` / `ListContainers` report it as `held`. Only an explicit start (`containarium wake <box>`, `StartContainer`) lifts it and restores autostart and wake. Before this, a box stopped on purpose was started again by a host restart or by any request to one of its routes. LXC runtime only; on the Kubernetes runtime `hold` returns `Unimplemented`.
