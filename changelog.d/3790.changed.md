- **A headless run may run `git merge-base` (#3790).** A platform-started run could not compute where a branch forked from its base, so a run that compares a pull request's head with its base could not make that comparison. `git merge-base` (and its `-C <dir>` and `--git-dir=` forms) is now allowed at every tool-access level; it only reads history. `git worktree` and `git archive` stay refused.
