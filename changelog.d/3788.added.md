- **`BUILD_TOOLS` runs can run Python tests** (#3788). `pytest` and
  `python3 -m pytest`, bare or with arguments, are now allowed at `BUILD_TOOLS`
  and `FULL_SUDO`; `python3 -c`, `python3 script.py`, `python3 -m pip` and bare
  `python3` remain refused, and nothing changes at `NONE`. pytest must already
  be on the box. The run wrapper's tool report now lists `pytest`.
