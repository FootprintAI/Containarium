- **A caller can tell its own box run from one started by hand** (#3668). `StartBoxRunRequest.client_token` is an opaque identifier the caller chooses (at most 128 bytes of UTF-8, no control characters). It is stored on the run record and returned as `BoxRun.client_token` by `StartBoxRun`, `ListBoxRuns` and `StopBoxRun`, including after a daemon restart, so a caller that lost a start's response can find its run by the token instead of by name and start time. A run started without one, including every run started from the CLI or over SSH, shows an empty token. The daemon never interprets or deduplicates it. Advertised as the `box_run_client_token` capability.
