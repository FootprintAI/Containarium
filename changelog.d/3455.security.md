- **Daemon logs quote tenant-supplied names** (#3455). Usernames, box and
  container names, tracker connection / project names, volume names, secret
  key names, process names, run ids and token ids in `containarium` daemon
  log lines are now written with Go `%q` quoting, so a value containing a
  newline or an escape sequence can no longer forge a log line or drive the
  operator's terminal. Log lines that carried these values now show them in
  double quotes (`user="alice"` instead of `user=alice`); update any log
  filters that matched the unquoted form.
